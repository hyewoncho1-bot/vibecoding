# 용돈 사용 내역 데이터 분석 애플리케이션

1학년 때 학습한 Python을 활용하여 Claude와 함께 바이브 코딩 방식으로  **용돈 사용 내역을 분석하는 애플리케이션**을 개발했습니다.

초기 버전인 **V1에서는 기본적인 기능 구현에 집중**했지만, 이후 **V3로 발전시키는 과정에서 다양한 오류 상황과 예외 케이스를 구체적으로 정의**했습니다.
그 결과 AI가 단순한 기능 구현을 넘어 복잡한 예외 처리 코드까지 생성하는 모습을 경험할 수 있었습니다.

이 프로젝트를 통해 AI에게 원하는 결과와 규칙을 **구체적으로 명시할수록 코드 수정과 반복 작업이 줄어든다**는 점을 깨달았습니다.
또한 바이브 코딩은 단순히 AI에게 코드를 맡기는 것이 아니라, **개발자가 요구사항과 규칙을 명확하게 설계하는 것이 중요하다**는 것을 배울 수 있었습니다.
